# Markdown → PDF

> 在线 Markdown 编辑器，即写即看，一键导出精美 PDF 或长图，完全在浏览器本地运行，无需注册，无需上传。

**[🚀 立即使用](https://zziilii.github.io/markdown-2-pdf-image/)**

---

## ✨ 功能亮点

- **实时预览** — 左右分栏，编辑即时渲染，所见即所得
- **Mermaid 图表** — 原生支持流程图、时序图、甘特图等所有 Mermaid 语法
- **代码高亮** — 基于 highlight.js，支持数十种编程语言语法着色
- **多种导出格式**
  - 📄 PDF（矢量文字，可复制搜索）
  - 🖼️ 长图（1×/2×/3× 高清像素）
- **多页面规格** — A4 / A5 / Letter / 手机竖版，灵活适配不同场景
- **多套主题** — 亮色 / GitHub / 复古 / 暗色，导出样式随心切换
- **导入 .md 文件** — 直接拖入或点击导入本地 Markdown 文件
- **亮/暗编辑模式** — 编辑器跟随主题，护眼舒适
- **纯前端，零隐私风险** — 所有处理均在本地浏览器完成，文档内容不会上传任何服务器

---

## 🛠️ 技术栈

| 模块 | 技术 |
|------|------|
| 框架 | Vue 3 + Vite |
| Markdown 解析 | marked |
| 图表渲染 | mermaid |
| 代码高亮 | highlight.js |
| PDF 导出 | jsPDF + html2canvas |
